# Face Recognition Bridge for Home Assistant

Интеграция связывает Home Assistant с моим отдельным backend-сервисом распознавания лиц. Само распознавание выполняется не внутри Home Assistant: интеграция только получает последние события через локальный API и превращает их в сущности и события HA.

Backend находится в репозитории `WWWorm92/Face_Recognition_Backend` и должен быть запущен отдельно.

## Что появляется в Home Assistant

- информация о последнем распознанном человеке;
- камера или источник события;
- оценка совпадения;
- события `face_recognition_match` и `face_recognition_unknown` для автоматизаций.

Например, событие можно использовать для уведомления, сохранения снимка или включения освещения. Я не рекомендую напрямую открывать замок только по результату распознавания лица.

## Установка через HACS

1. Откройте HACS.
2. Добавьте этот репозиторий как пользовательский репозиторий типа `Integration`.
3. Установите `Face Recognition Bridge`.
4. Перезапустите Home Assistant.
5. Откройте `Настройки → Устройства и службы → Добавить интеграцию`.
6. Найдите `Face Recognition Bridge`.

## Настройка

При добавлении интеграции указываются:

- `base_url` — адрес backend API, например `http://192.168.1.10:8787`;
- `api_token` — токен backend, если он включён;
- `scan_interval` — интервал опроса.

Home Assistant должен иметь сетевой доступ к backend. Если сервис работает в другой VLAN или Docker-сети, проверьте маршрутизацию и правила firewall.

## Как это работает

Интеграция периодически запрашивает последнее событие у backend. При появлении нового результата она обновляет сенсоры и отправляет событие в Home Assistant. Такой подход проще отдельного MQTT-моста, но задержка зависит от выбранного интервала опроса.

## Ограничения

- без backend интеграция ничего не распознаёт;
- сейчас используется локальный polling, а не постоянное соединение;
- формат сущностей и событий ещё может меняться;
- проект экспериментальный и тестировался на моей конфигурации Home Assistant;
- фотографии и биометрические данные должны храниться и обрабатываться с учётом местных требований.

При проблемах сначала проверьте, открывается ли API backend из той же сети, где работает Home Assistant.
